Company Overview  
Company Name: All in One Care  
This idea was created around the idea that healthcare management should be simpler and more organized. Instead of having patients navigate several different systems.  
Project Overview 
The All in One care project is a development of a patient-centered healthcare application that allows users to organize and manage important aspects of their healthcare from one application.
The application will provide users with a centralized dashboard where they can access information such as upcoming appointments, medication reminders, health information, and healthcare-related tasks.
The project will focus on creating a simple and user-friendly experience. The application is intended to reduce the need for patients to switch between multiple healthcare applications and websites.
